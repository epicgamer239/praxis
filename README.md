# Praxis

> **Real-World Social Action RPG**  
> _Target Competition:_ Congressional App Challenge 2026 (VA-10)

Praxis is an "anti-screen screen tool" that gamifies offline real-world interactions, civic deeds, and physical habits. Users complete real-world quests spanning four core attributes (Wisdom, Charisma, Civic Reputation, Vitality), upload photo proof of work, and level up their character sheet only after receiving peer consensus vouches from their private Guild.

---

## 🛠 Tech Stack

- **Framework:** Next.js 14+ (App Router, React, TypeScript)
- **Styling:** Tailwind CSS (Custom Obsidian & Earthy Attribute Theme)
- **Backend & Database:** Google Cloud Firestore (Real-time collections)
- **Authentication:** Firebase Auth (Email/Password & Google OAuth)
- **Media Storage:** Firebase Storage (Compressed photo proof hosting)
- **Icons:** Lucide React
- **Platform:** Progressive Web App (PWA) running on iOS, Android, and Desktop

## 🚀 Quickstart for Collaborators

Follow these steps to get the local development environment running:

### 1. Prerequisites

Ensure you have the following installed on your machine:

- [Node.js](https://nodejs.org/) (`v18.17.0` or higher recommended; LTS preferred)
- [Git](https://git-scm.com/) or [GitHub Desktop](https://desktop.github.com/)

### 2. Clone the Repository

Using GitHub Desktop:

- Go to **File** → **Clone Repository...** → Select `praxis` → Choose local path.

Or via Terminal:

```bash
git clone https://github.com/YOUR_USERNAME/praxis.git
cd praxis
```
